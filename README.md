# 风电场检修隔离与作业许可协调平台

源提示词编号：9。覆盖风机、箱变和线路隔离点、锁定与验电步骤、作业许可状态流、跨班组冲突检测、实时提醒、断线重连、失败操作重试和审计记录。

## 断网检修对账规则

检修中端侧断网时，现场把许可步骤、隔离措施记在本地（`outbox` 队列）；线路恢复后在「断网对账」页（`/sync`）与调度端快照逐项对账：

- **字段级合并，不整份替换**：双方都碰过的许可，仅接收无争议字段；端侧与调度端取值不一致的冲突字段保留现场值并挂起，由值班负责人在对账中心裁决（按现场 / 按调度）。
- **调度端动作优先**：仅调度端改过的字段直接接收；调度端在断网期间已审批、签署或解除隔离时，受影响的验收结论立即失效，须重新确认后方可继续。
- **中断续传 + 日志幂等**：对账可随时中断；再次提交只补未完成许可。对账日志使用确定性 ID（`AE-RC-<许可>-<类型>`），`addAudit` 按 ID 去重，重复提交不会重复生成操作日志。
- **旧修订回填**：历史数据缺少 revision、隔离点设备归属、步骤责任人等原始字段时，由 `backfillLegacyPermit` 按旧修订号回填索引（`legacyIndex`），隔离措施与操作日志仍可查询；旧版本 localStorage（v1）启动时自动迁移到 v2。
